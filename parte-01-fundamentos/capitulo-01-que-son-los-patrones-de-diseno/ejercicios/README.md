# 📝 Ejercicios propuestos

## Ejercicio 1 - Identificar problemas

Piensa en una aplicación que hayas desarrollado o utilizado.

Identifica tres posibles problemas de diseño que podrían aparecer cuando la aplicación crezca.

Para cada uno responde:

- **¿Cuál es el problema?**
- **¿Qué parte del sistema podría verse afectada?**
- **¿Qué responsabilidad está implicada?**
- **¿Qué consecuencias tendría mantener el diseño actual?**

---

## Ejercicio 2 - Nueva implementación

Amplía el ejemplo de **notificaciones** creando:

```java
PushNotificador
```

La nueva implementación debe utilizar la interfaz:

```java
Notificador
```

y no debes modificar:

```java
ServicioNotificaciones
```

---

## Ejercicio 3 - Reflexión

Piensa en una situación en la que hayas añadido una abstracción a un proyecto simplemente pensando:

> "Quizá algún día la necesitemos."

Pregúntate:

**¿Existía realmente un problema que justificara esa complejidad?**
