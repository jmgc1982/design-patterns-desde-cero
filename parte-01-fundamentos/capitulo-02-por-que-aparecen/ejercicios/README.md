# 📝 Ejercicios propuestos

## Ejercicio 1 - Detectar la evolución

Piensa en una aplicación que conozcas.

Identifica:

1. **Una funcionalidad que inicialmente fuera sencilla.**
2. **Tres cambios que podrían aparecer con el crecimiento del sistema.**
3. **Qué parte del código podría verse afectada.**
4. **Qué problemas de diseño podrían aparecer.**

---

## Ejercicio 2 - Ampliar el ejemplo

Añade al ejemplo de `ProcesadorPago` un nuevo método:

```text
Apple Pay
```

Después añade:

```text
Google Pay
```

Observa cómo aumenta la **responsabilidad de la clase**.

---

## Ejercicio 3 - Analizar el contexto

Imagina dos aplicaciones:

### Aplicación A

Una pequeña aplicación interna que solamente procesa pagos mediante tarjeta.

### Aplicación B

Una plataforma internacional que soporta diez métodos de pago y añade nuevos métodos cada pocos meses.

Pregunta:

> ¿Deberían utilizar exactamente el mismo diseño?

Justifica tu respuesta.

---

## Ejercicio 4 - Reflexión

Piensa en una ocasión en la que hayas introducido una abstracción "por si algún día hacía falta".

Responde:

> ¿Existía realmente un problema que justificara esa abstracción?
